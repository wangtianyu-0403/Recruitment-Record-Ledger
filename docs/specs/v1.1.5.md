# v1.1.5 更新修复

修复下载更新后界面仍停留在旧版本，以及快捷方式打开旧安装的问题。

- 下载和校验成功后，必须确认更新助手就绪才退出当前程序；助手启动失败时显示日志目录并保留当前窗口。
- 使用当前程序的真实进程 ID，等待其退出后替换安装目录。
- 自动更新和本地同步复用同一个事务式安装脚本，更新快捷方式的目标、工作目录和启动参数。
- 发布包附带版本标记；安装前验证它与用户接受的目标版本一致。
- 新程序使用独立 PyInstaller 环境启动，确认窗口正常响应后才报告成功；启动失败时恢复旧程序和快捷方式。
- 保留用户数据库、设置和安装备份。更新 GitHub、原生本地仓库和指定桌面快捷方式。

验收使用临时数据与目录：助手握手、旧地址快捷方式修复、版本不匹配拒绝安装、启动失败回滚、完整新窗口启动。发布前运行全套测试并实际启动打包程序。
