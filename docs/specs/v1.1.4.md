# v1.1.4

用户已确认以下范围及验收点：

- 新增和编辑招聘记录支持可选的本地简历文件路径。
- 主信息表中，公司官网右侧增加本地简历列及打开简历按钮。
- 工具栏增加个人页和简历页，各保存独立的全局文件或文件夹路径。
- 两个入口均显示打开、修改本地文件目录菜单，路径重启后保留。
- 文件使用系统默认程序打开，文件夹使用系统文件管理器打开；无效路径和系统打开失败有中文提示。
- 备份数据库、恢复数据库移至工具栏最后。
- 升级旧数据库保留记录、历史、置顶和手动排序。
- 梳理现有结构并合并重复逻辑，不引入新运行依赖。
- 更新版本为 1.1.4，验证后提交并推送 GitHub main。

## 打包验证发现

打包机 PATH 中的 Poppler 提供了 ICU 78 的同名 icuuc.dll，而 Qt 需要 Windows 系统 ICU 的无版本后缀接口。原打包结果无法导入 QtCore。Windows 构建和本地同步脚本统一复用已提交的 spec，在 spec 内限制依赖搜索 PATH；重建后直接读取发布 EXE 内的归档代码、加载发布目录的 Qt DLL，并在注入的临时数据目录验证启动、版本和简历路径保存。
